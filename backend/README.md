
# FitTrack - TaskFlow Backend API

Node.js ve Express.js ile geliştirilmiş
sağlık ve spor görev yönetim sistemidir.

## Teknolojiler
- Node.js
- Express.js
- JavaScript
- JSON
- Postman

## Kurulum
npm install
node server.js

## API
- GET /tasks
- GET /tasks/:id
- POST /tasks
- PUT /tasks/:id
- DELETE /tasks/:id

## Özellikler
- Görev CRUD işlemleri
- Logger middleware
- JSON dosyasında veri saklama
